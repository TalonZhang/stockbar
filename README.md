# StockBar

<img src="Resources/AppIcon-1024.png" width="96" alt="StockBar 应用图标">

StockBar 是一个轻量的 macOS 菜单栏股票与场内基金行情应用。菜单栏只显示一个小图标，点击后即可查看上证指数、A 股和场内基金的名称、涨跌幅与现价。

## 功能

- 上证指数固定显示在列表第一行；
- 顶部分组选项卡，支持新建、重命名和删除自定义分组；
- 股票和场内基金（ETF、LOF 等）可混合添加，同时显示名称、涨跌幅和现价；
- 基金价格保留三位小数，股票与指数保留两位小数；
- 交易时段每 5 秒刷新，非交易时段每 60 秒检查一次；
- 点击列表下方“＋ 添加自选”，统一在小窗输入六位股票或场内基金代码并按回车添加；
- 支持中文名称、拼音缩写搜索，显示候选名称、市场和代码后选择添加；
- 鼠标移到自选股行时显示删除按钮；
- 直接拖动股票行调整自选股顺序；
- 支持腾讯财经、东方财富以及自动故障切换；
- 菜单提供东方财富财经快讯入口，点击后在默认浏览器阅读官网；
- 支持系统开机启动；
- Intel 与 Apple Silicon Universal 2；
- 在带 Touch Bar 的 Mac 上保留 Touch Bar 行情，无 Touch Bar 的 Mac 会自动隐藏相关功能。

> StockBar 使用非官方公开行情端点，并在支持的机器上使用 macOS 私有 Touch Bar API。它适合个人查看行情，不构成投资建议，也不适合提交 Mac App Store。

## 下载与安装

1. 打开仓库右侧的 **Releases**，下载最新版 `StockBar-版本号.dmg`。
2. 双击 DMG，把 `StockBar.app` 拖入 `Applications`。
3. 从“应用程序”启动 StockBar。应用没有 Dock 图标，启动后会出现在屏幕顶部菜单栏。

启动或再次打开应用时只显示菜单栏图标，不自动展开行情列表；点击菜单栏图标查看行情。首次安装或升级到此版本时，会尝试把图标放到靠右的位置，之后保留手动调整的位置。macOS 管理最终排序，第三方应用不能保证始终最右或永不隐藏；可以按住 Command 拖动图标调整位置。

当前免费发布版使用临时签名，没有 Apple Developer ID 公证。macOS 首次打开时可能阻止运行：

1. 先尝试打开一次 StockBar；
2. 打开“系统设置 → 隐私与安全性”；
3. 找到 StockBar 的拦截提示，点击“仍要打开”；
4. 再次确认打开。

只应从本仓库 Release 下载，并可使用 Release 中的 `SHA256SUMS` 校验文件完整性。

把 DMG 和 `SHA256SUMS` 下载到同一个目录后，可在该目录运行：

```bash
shasum -a 256 -c SHA256SUMS
```

升级时先退出旧版 StockBar，再把新版本拖入“应用程序”并替换。现有自选会自动迁入默认“自选”分组，分组名称、组内顺序和设置会保留。

## 使用说明

### 查看行情

点击菜单栏的趋势图标即可展开列表：

- 红色代表上涨；
- 绿色代表下跌；
- 上证指数固定在第一行，不能删除或移动；
- 菜单顶部显示最后更新时间和实际使用的行情源。

### 添加自选股

点击股票列表下方的“＋ 添加自选”按钮进入输入小窗，边输入边显示匹配结果；输入六位股票或场内基金代码后按回车直接添加。例如：

- `600519`：贵州茅台；
- `000001`：平安银行；
- `300750`：宁德时代；
- `512890`：红利低波 ETF；
- `510310`：沪深 300 ETF；
- `159915`：创业板 ETF；
- `161725`：白酒基金 LOF；
- `920002`：北交所股票示例。

支持沪深北 A 股，以及上海 `5` 开头、深圳 `15`、`16`、`18` 开头的场内基金代码；添加前会向所选行情源验证代码。场外申购基金不在支持范围内。基金显示的是场内交易价格和涨跌幅，不是基金净值估算。原有自选、排序和删除操作同样适用于基金。

菜单中不再放置输入框。全部添加操作都从“＋ 添加自选”按钮进入原生输入小窗，支持中文输入法、组词候选和插入光标。

### 通过名称或缩写搜索

在输入小窗中输入中文名称、拼音首字母或部分代码，例如 `中际旭创`、`zjxc`、`红利低波`。停止输入约 300 毫秒后，下方自动显示结果，不需要先按回车搜索。

应用按结果数量处理：

- 唯一结果：直接显示该结果，按回车验证并添加；
- 多条结果：直接显示名称、沪深北市场和六位代码，最多 8 条，可用方向键或鼠标选择；
- 没有结果：保留输入内容并显示提示；
- 可以继续修改关键词，停止输入片刻后更新匹配；打字过程中不会自动添加；
- 用鼠标选择后点“添加”，或用方向键选择、回车添加，也可双击候选；
- 添加前会通过当前行情源重新验证，完成后回到行情列表；
- 添加目标是打开搜索时的分组，取消搜索不会更改自选；
- 支持股票和场内 ETF、LOF，不显示港美股、指数或场外基金；
- `Esc` 或关闭按钮可取消。结果过多时可以补充名称或使用六位代码。

中文输入法组词期间不会搜索或提交，确认中文上屏后再按回车添加。完整中文名称也按匹配数量处理；相似基金简称返回多条时仍需选择。六位代码保持直接回车添加。

### 分组

- 默认“自选”保留升级前的全部自选记录及顺序，不能改名或删除；
- 点击顶部 `＋` 新建分组，例如“科技”“医药”“场内基金”；
- 分组名称最多 10 个字，选项卡最多显示前 4 个字，悬停显示全名；
- 分组较多时，在选项卡区域横向滚动查看；
- 点击选项卡切换分组，再点击下方“＋ 添加自选”会添加到该分组；
- 点击 `⋯ → 从其他分组添加`，可把已有自选加入当前分组；
- 同一只股票或基金可在多个分组中，各组独立排序、删除，互不影响；
- `⋯` 菜单提供当前分组的重命名和删除功能；
- 每个分组都固定显示上证指数，并记住上次选择的分组；
- 行情请求按所有分组去重合并，切换分组直接使用已有行情缓存。

### 删除与排序

- 把鼠标移到某只自选股行，点击最右侧圆形叉号即可删除；
- 按住自选股整行并拖到另一行，松开后保存新顺序；
- 上证指数不会显示删除按钮，也不参与拖动排序。

### 行情源

菜单中的“行情源”提供三个选项：

- **自动切换**：优先腾讯财经，失败或数据不完整时使用东方财富补齐；
- **腾讯财经**：固定使用腾讯行情；
- **东方财富**：固定使用东方财富行情。

请求失败时会保留最后一次成功行情。选择“立即刷新行情”可以手动请求最新数据。

### 财经快讯

点击菜单中的“财经快讯（东方财富）”，使用默认浏览器打开[东方财富全球财经快讯](https://kuaixun.eastmoney.com/)。

该入口仅打开官方网站；StockBar 不抓取、缓存或后台刷新新闻，也不内嵌网页。网站的内容加载和隐私规则由浏览器及东方财富网站负责。

### 开机启动

勾选菜单中的“开机启动”即可通过 macOS `SMAppService` 注册登录项。系统可能要求在“系统设置 → 通用 → 登录项与扩展”中批准。

建议先把 StockBar 放入 `/Applications`，再开启此选项。应用升级或移动后会尝试把登录项重新注册到当前路径。

### Touch Bar

StockBar 会先通过 IOKit 检测物理 Touch Bar：

- 没有 Touch Bar 时，不加载私有框架、不启动 watchdog，也不显示 Touch Bar 菜单；
- 检测到 Touch Bar 且系统接口可用时，保留原来的跨 App 行情栏和恢复按钮；
- Touch Bar 接口属于 macOS 私有 API，未来系统版本可能改变其行为。

## 隐私与网络

StockBar 不包含广告、账号系统、埋点、遥测或崩溃上报。

保存在本机的数据：

- 分组名称、各组自选代码与顺序、上次选择的分组；
- 行情源选择；
- 开机启动注册路径。

这些设置位于当前用户的 `dev.talon.stockbar` 偏好设置域，不会写入 GitHub 仓库，也不会由应用主动上传。

行情请求会把股票、场内基金代码发送到所选行情源：

- 腾讯财经：`qt.gtimg.cn`；
- 东方财富：`push2delay.eastmoney.com` 的行情节点。

名称和缩写搜索会把当前输入的关键词发送到 `smartbox.gtimg.cn`，必要时使用 `searchapi.eastmoney.com` 作为备用搜索源。搜索关键词不保存到本地历史，也不上传分组名称。

应用不读取通讯录、照片、邮件、浏览器数据、剪贴板或其他个人文件，也不需要 API Key。

“财经快讯（东方财富）”仅通过默认浏览器打开固定官网地址，不向该地址附加分组名称、自选代码或搜索词；访问网站后的行为遵循浏览器和网站的隐私规则。

## 卸载

1. 在 StockBar 菜单中关闭“开机启动”；
2. 选择“退出 StockBar”；
3. 把 `/Applications/StockBar.app` 移到废纸篓。

如需同时清除本地自选股和设置，可在终端执行：

```bash
defaults delete dev.talon.stockbar
```

## 从源码构建

依赖：

- macOS；
- Apple Clang / Command Line Tools；
- `make`、`lipo`、`codesign` 和 `hdiutil`；
- 无第三方代码依赖。

构建 Universal 2 应用：

```bash
make
```

产物位于：

```text
build/StockBar.app
```

启动开发构建：

```bash
make run
```

运行离线代码映射、价格精度、分组迁移、名称限制和持久化测试：

```bash
make test
```

运行 AppKit 分组选项卡布局、切换和控制器联动测试（需要图形会话）：

```bash
make ui-test
```

运行硬件检测、三行情模式的股票与基金混合请求及添加验证：

```bash
make smoke-test
```

运行中文、拼音缩写、基金多结果和无匹配的在线搜索测试：

```bash
make search-smoke
```

生成 DMG 和 SHA-256 校验文件：

```bash
make release
```

发布产物位于 `dist/`。

重新导出应用图标：

```bash
make icon
```

图标源文件为 `Resources/AppIcon-artwork.png`，导出说明见 [Resources/AppIcon.md](Resources/AppIcon.md)。菜单栏图标独立使用系统符号，不会受应用图标更新影响。

## 技术说明

- Objective-C、AppKit、Foundation、IOKit；
- x86_64 最低目标 macOS 10.14；
- arm64 最低目标 macOS 11；
- `NSURLSession` 批量请求行情；
- `NSUserDefaults` 保存本地配置；
- `SMAppService.mainAppService` 管理登录项；
- 私有 Touch Bar 符号通过 `dlopen`、`dlsym` 和 Objective-C runtime 动态探测，缺失时不会产生链接崩溃。
